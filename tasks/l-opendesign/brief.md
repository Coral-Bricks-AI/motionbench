# The brief

Make a 14-second Dribbble-level UI motion piece at 120 BPM, 7 bars, something happening on every beat. One shape, never cut: it morphs from a Generate button into a loader, a check, a dynamic island, a music player with a play/pause morph, a scrubbed progress bar, a volume slider that stretches when dragged past max, a toggle, a liquid tab indicator, a chart that draws itself with a hover tooltip, a ⌘K palette you type into, a toast, and back to the button. A cursor drives every change with real clicks and drags. Light warm-gray canvas, black and white components, one clean UI font (Geist). Springs everywhere, a tiny overshoot at most. The last frame is the first frame, so it loops.

---

This is the starter prompt of Open Design's "One-Shape UI Motion" example, used unchanged. Open Design's motion skill is installed at `skills/open-design-hyperframes/` (start with its `SKILL.md`); Geist is in `assets/fonts/`. There is no music file: the beat is the 120 BPM grid from the first frame.

## Tagging for the review tool (added by motionbench)

Deliver `index.html` as in `CONTRACT.md`, 1920×1080, exactly 14 seconds. Tag the one shape `data-role="shape"` and the cursor `data-role="cursor"`.
